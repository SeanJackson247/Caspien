# CLAUDE.md -- BytecodeParser (shared bytecode representation)

Package `caspien.bytecode` (`BytecodeToken`, `BytecodeStatement`, `BytecodeProgram`, `BytecodeParser`, `BytecodeSerializer`), used by `ASTGenerator/` (builds a `BytecodeProgram`; `Main` serializes), `Optimizer/`, `LowerOrderGenerator/` and `Codegen/` (`Main` parses the LOB once, the backend walks the `BytecodeStatement`s); `README.md` has the rules. Sources only: each stage compiles `../BytecodeParser/src/main/java` into its own `out/` (rebuild all four after a change here). Imports no stage. Per stage only the entry class calls parser/serializer (`Optimizer`, `LowerOrder`; `Main` in ASTGenerator and Codegen); passes build generated lines with `BytecodeStatement.fromText`. The format carries HOB and LOB alike. Check: `tests/bytecode_phases_check.sh`.
