# ASTGenerator (Caspien front end) -- current state

Stage 1 of the toolchain: Caspien source -> plain-text high-order bytecode (HOB). History lives in git; this file describes only what is true now. The root `/home/claude/caspien/CLAUDE.md` covers the whole project.

Struct `extends`/`abstract` are gone (`0345aaa`): composition plus interfaces only, flat `Class` enum, `x instanceof Struct` (x interface-typed, struct name only), `x implements IFace` (x struct-typed, interface name only), the `cast` statement is removed.

## CLI and pipeline
`java caspien.Main -i main.caspien out.txt` (normally driven by root `Compiler.java`, which chains all four stages). The output file, stdout and `output.txt` get the HOB. `compiler.config` (CWD-relative, REQUIRED, no fallback) lists calling conventions and the default one.
Stages in `src/main/java/caspien/`:
- `Lexer`, `Token`, `TokenType`: tokens; hex/binary/`_` integer literals are normalised to decimal here (`Token.radixLiteral` only blocks float merging).
- `Parser`: lines to nested tokens; gathers keyword blocks (`gatherKeywordBlocks`), constructors, impls, `match @lock`, `&&then`/`||then` merge, `?` sugar expansion.
- `RpnConverter`, `TreeBuilder`: operator precedence, tree. `TreeDump`: debug.
- `ImportResolver` (paths relative to the IMPORTING file), `DupExpander`, `GenericsExpander` (monomorphisation; also `dyn:<T>`, `wrap:<T>`, `sat:<T>`, `recv.method:<U>` keep `genericArgs`).
- `TypeChecker` (~15k lines, known debt): all semantic rules, move/proof tracking, synthesises async trampolines/handle structs, lowers `@recursive` to a bounded loop.
- `BytecodeEmitter`: walks the checked tree, emits HOB.
- `GasReport`: `--audit` sections worst-case gas, stack depth estimate and heap allocation count, computed from the emitted HOB text (loops found by `@for_N`/`@loop_N` label pairs, literal `for` bounds from the `$for_range` type; one walker over (net, peak) path values, per-call-site argument values (`runEvals`: an unbounded callee is re-solved with the literal/known values the call passes; `valueAt` walks back through label-free code), struct-member credit (`St.deep`, `deepOk`), metrics GAS/HEAP/COUNT/LIVE (LIVE = peak live heap: allocations charged on the `@new_ok_`/`@alloc_ok_` label, frees credited by `analyzeCredits`, a must-analysis, with per-entry-edge contexts for catch pads; test `heap_live_check.sh` runs variants under `alloc_shim.c`); stack = call-graph max of frame estimates; an `@event_loop` program lists its `@with_tick`/`@tick` slices as roots and never the loop itself, found via `FUNC_DECORATE`; the loop's termination class is read off the tick: no `@throws` = non-terminating, `@throws` with a reachable `RET` (`canReturn`) = unbounded, no reachable `RET` = bounded, one tick; test in `gas_check.sh`); cost table in `docs/COMPILER_REFERENCE.md`; tests `tests/gas_check.sh`, `tests/stack_check.sh`. `--viz` (`GasReport.viz`, Main flag + env `CASPIEN_VIZ_FILE`) writes the HTML circle diagram of the entry function and its direct callees, sized by stack depth; test `tests/viz_check.sh`.
- `CompilerConfig`, `CompilerException` (every fatal error).

## Language rules a maintainer must know
**Types/storage.** Storage: `owns`, `ref`, `raw`, `auto`, `static`; `some` = non-null. Plain `ref`/`owns` are nullable and need `match Some(x){}` (or `some`) to dereference. Mutability `mut`/`imut`; literals and struct literals are indeterminate and coerce. `raw` needs an addressable lvalue or a string literal (bind others to a `let`); `auto` needs an addressable local and may NOT point at a static/global or into a swap-lock static's members (`checkAddressOf`; shared memory would leave its lock, and it miscompiled; test `auto_static_error_test`); `auto` of a variable that is itself a pointer (`owns`/`ref`/`raw`/`auto`) is an error (it produced the address of the variable: stack corruption; `auto_pointer_variable_error_test`); `static x` of a struct-typed global is an error (lowered as a struct copy into a pointer slot; `static_struct_pointer_error_test`). `auto` points into a stack frame, so it may not outlive it: no function or method returns an `auto`, no struct member is an `auto` (also arrays / dynarrays of them), and no parameter or local is an array/dynarray of `auto` (`requireNoAutoReturn`, `validateNoAutoStructMembers`, `requireNoAutoContainer`; no unsafe escape; tests `auto_return_error_test`, `auto_return_method_error_test`, `auto_member_error_test`, `auto_fixed_array_member_error_test`, `auto_dynarray_member_error_test`, `auto_container_param_error_test`, `auto_container_local_error_test`); `auto` parameters and locals are fine. A struct member cannot be a plain by-value struct parameter anywhere (by-value struct PARAMETERS are rejected); structs may be returned by value (RVO). Recursive structs are banned except through a plain (nullable) `ref` member, never `ref some`/`owns`/`raw`/`auto` (`validateNoRecursiveStructs`/`detectStructCycle`; `ref v[i].n` of a dynarray element works through `lookupDeclaredTypeStructurally`); recursion only via `@recursive` tail self-call (see below). Structs are padded to natural alignment (`@unpadded` is an error).
**Ownership.** `owns` values are moved on pass/assign, also when written `mut x`/`imut x` (the wrapper is transparent; use after move is an error); scope exit, `return`, `throw`, `break`, `continue` destruct the live owns locals (`collectOwnsToDestruct`, lists stored on the token). A slot moved on only SOME paths reaching a merge (`finishBranchMerge`, `partlyMovedSlots`) stays "moved" for the use-after-move rule but is still destructed at later exits (a move nulls the slot, the destruct is a no-op there); before 6 Oct that path leaked. Test `cond_move_test` + `cond_move_check.sh` (checks the ghost table's entry count: valgrind cannot see this leak, the table keeps blocks reachable). One function-wide slot per NAME: sibling scopes may reuse a name with another (scalar) type, but a name whose types differ where one needs generated drop glue (owned dynarray of owning elements, struct with an owns member) is a compile error (`requireOneOwnsTypePerSlotName`; the drop-glue pass resolves `GT_DESTRUCT name` through one name->type map; a catch parameter `e` plus a local `e` counts; test `same_name_owns_error_test`). Reassigning an owns target destructs the old value first (pointer-crossing targets use `DUP_TOP` + `GT_DESTRUCT_ADDR`).
**unsafe.** Needed for: `raw` construction, `deref`/`clone` of a `raw` pointer (tags `deref`/`clone`, on top of the alive proof), `memcopy`, extern calls (except where declared safe), unbounded `loop{}`, statics/globals (swap-lock structs exempt; atomics need the `atomic` tag), direct access to a `swap` mutex field (tag `atomic` too), unsafe dynarrays (`unsafe dyn`), `@guard` use not proven locked, direct `swap` field access. `deref`/`clone`/divisor/float-state/`@lock` proofs are NOT relaxed by unsafe: only `assume match` (in `unsafe assume{`) vouches, with expression keys (`exprKeyOf`, assume mode). Tags (`unsafeBypass`/`checkOrBypass`, `validateUnsafeBlockTags`) are checked both ways. NOT needed for `throw`, `try`, `?`, passing/stepping raw pointers. `deref(...)` is never a write target.
**Pointer arithmetic** on `raw`: `++ -- += -= p+n n+p p-n p-q` scale by pointee size (raw void = 1); p-q is s64; integer side u64/s64.
**Literal adaptation.** An integer literal takes the slot/other-operand type if it fits (args, return, assign, struct members, arithmetic, compares, compound assign, `bits_*`, array literal elements), else error. A variable is never a literal. Overloads try no-adaptation candidates first. Float literals default f32 and adapt to f64; no implicit f32/f64 mixing (`as f64`, `wrap:<f32|f64>` -> `FCONV`).
**Enums.** `@non_exhaustive` enum: last variant `default`; a match needs `default` iff some variant is unnamed, and `default` is an error when all are named (`checkEnumMatch`). Plain enum: `default` illegal.
**Casts.** `as` only: alias relabel (no code) or same-signedness widening (`SEXT`/`ZEXT`). Narrowing needs `match x fits T{ x as T }` (`TRUNC`), `wrap:<T>(x)` (low bits) or `sat:<T>(x)` (clamp; arg must be a variable/field/literal). Signed `/ % < <= > >=` lower to `SDIV_INT` etc. `x implements/instanceof` see top note.
**Proofs (match/in/into/within/fits).** `match i in arr{}` / `into arr{}` (write-authorizing) prove bounds for `arr[i]`; a bare fixed array is rewritten to `range(arr)`; a plain `in` proof cannot authorise writes; proofs are invalidated by writes to the index. `range(x)` folds: literal/fixed array -> `PUSH 0 / PUSH len`, safe dynarray -> bare `imut range` via `LEN`; unsafe dynarray rejected; slicing `arr[a..b]` is an error (no slice type). `within` always emits `WITHIN`; `u64 in string` emits `IN_SCAN` (not a match condition). `match Some(p)` is the alive proof (`GT_ALIVE_CHECK`); a `ref some` LOCAL carries an implicit alive proof from each assignment. `ProofKills` (8 Oct) ends these proofs at anything that may free: `unsafe` blocks (not `unsafe assume{`), assignment over an owns slot, `resize`, `par`/`await`, an owner moved into `new`/`dyn`, a call to a function that does any of these or takes an `owns` parameter or whose target is unknown. The checker records uses (`isProvenAlive`, `refSomeRead`) and events in source order with the loop ids they sit in; `TypeChecker.checkProofKills` (called from `BytecodeEmitter.emit` next to `LockNestingCheck`) decides after the whole program is checked (a use needs one covering proof with no killing event before it, nor one in a shared loop). A second `match Some(x)` is allowed once the first proof has seen an event (renewal). `ref some` parameters/`self` get an implicit proof at entry (`ProofKills.implicit`); each proof carries its pointee struct type (`MatchPattern.pointee`) and each event the types it can destroy (`TypeChecker.destroyedTypes`: ownership closure; null = anything: `unsafe`, `par`/`await`, unknown target), so `resize` of a fresh local or freeing an unrelated type does not end it; the `unsafe` kill is recorded at the END of the block; a `match Some(x)` condition read is suppressed (`suppressReads`). `GenericsExpander.deepClone` now also copies `hasBlock`, `isTryBlock`, `isStatic`/`isConst`, case/for match flags, enum/range numbers, asm text, literal radix (8 Oct: a block-form `assume match c{...}` in a generic body lost its whole block; test `generic_flags_test`). Member refs are ordinary `match Some(path)` proofs (slot key = the path, errors name it). Not covered: branch exclusivity (a kill in the then-branch also flags a use in the else-branch). Tests `ref_free_*_error_test`, `ref_proof_kill_test`. `else{` must start its own line. `&&then`/`||then`: lazy chain, legal only at the root of an `if`/`elseif` condition or under other lazy nodes; emitted as CMP/JMP cascades, no AND/OR.
**match @lock.** `match @lock x{ OPEN:{} CLOSED:{} }` on a struct with a `swap` mutex field; OPEN plants the struct-lock proof; every CLOSED path must end in `continue` (retry), `break` (give up), `return` or `throw`; `CLOSED:default(...)` policy bodies get an implicit `continue`. Struct-level `@lock(match self.X : OPEN)` requires X to be the first declared member and forbids any `ref` (`ref some` too) or `auto` ANYWHERE inside it: direct members, nested structs, fixed arrays, dynarrays, behind `owns` members, and in every struct implementing an interface-typed member's interface (9 Oct: an `owns` interface member hid a `ref` implementer, race demo), recursively (`validateNoPointersInLockStructs`, run after all structs are flattened; tests `lock_ref_member_error_test`, `lock_ref_member_regular_error_test`, `lock_auto_member_error_test`, `lock_nested_pointer_error_test`, `lock_array_pointer_error_test`, `lock_fixed_array_pointer_error_test`, `lock_dynarray_pointer_error_test`, `lock_owns_pointee_pointer_error_test`, `lock_interface_pointer_error_test` (+ `lock_interface_plain_test`); SWAP-lock structs only (regular locks are not reachable from two threads in safe code): an `owns`-bearing value assigned into one (member, nested path, element, struct-literal member) must be a FRESH allocation (`null`, `new`, `dyn`, `clone`, no owned variable moved inside; a call result is refused): a `ref` taken before a move-in stays valid (ids) and raced with the lock holder (9 Oct demo); `requireFreshIntoSwapLock`, tests `lock_move_in_error_test`, `lock_move_in_new_error_test`, `lock_call_result_error_test`, `lock_literal_move_in_error_test`; `owns` members of plain data are fine, test `lock_owns_member_test`; a `raw` member is still allowed, filling it needs `unsafe`; a `static` pointer can only name a global, which needs `unsafe` too); method form `@lock(match i into self.backing)` is a compile-time proof contract only (callee may be inlined). Block `lock x{}` unchanged. Atomic types: plain reads/writes emit `ATOMIC_PUSH`/`ATOMIC_ASSIGN`; compound assign/`++`/`--` on atomics rejected; `swap` RHS must be a variable/literal/enum variant; emits `ATOMIC_SWAP`.
**No nested locks.** `LockNestingCheck` (run by `BytecodeEmitter.emit` before emission): inside the OPEN case of a `match @lock` (`Token.isLockSpinLoop`, OPEN branch = the lowered `if`'s childs) or the body of a `lock x{}` block, any lock acquisition, directly or through the call graph (`resolvedCallTarget`), is a type error naming the chain. Exempt: the `@gt_*` functions and everything reachable from them (the ghost table's lock is always innermost). Not followed: `call()`, `await`/`par` targets, `@drop` hooks run by drop glue. Tests `nested_lock_error_test`, `nested_lock_call_error_test`, `nested_lock_alloc_test`.
**No waiting in a critical section.** The same walk (`LockNestingCheck`) rejects `yield`, `sleep`, `par`, `await` inside a held lock, directly or through any callee (`waitKindOf`, `pathToWait`); no unsafe escape; externs/unsafe loops not judged; `@gt_*` exempt. Tests `lock_wait_error_test`, `lock_wait_call_error_test`, `lock_wait_par_error_test`.
**Bounded lock retry.** In safe code (every function except the `@gt_*` ones) a hand-written CLOSED body that contains a retry `continue` is a compile error (`lockRetryContinuesSeen`, checked after the CLOSED body; message "must say how many times"); the bound comes only from `CLOSED:default(n)`. A registered `impl default match @lock` policy gets `$lm_tries` + `$lm_tries++; if $lm_tries > limit{ break }` (limit = the policy's second parameter when it is a u64, else `LOCK_SPIN_LIMIT` 1e9), so even a policy that always `continue`s is stopped. With no policy registered, `CLOSED:default(n)` is built in (`$lm_limit`, retry n times, then `break`). A CLOSED with no retry (`break`/`return`/`throw` only) is a single attempt with no counter. Give-up = `break` out of the spin, without the lock. `--audit` does not read the bound yet (a function with a spin still shows unbounded). Tests `lock_spin_limit_test`, `lock_bare_retry_error_test`, `lock_custom_retry_error_test`.
**Event loop and `@tick`.** `@tick` may be `@throws`. The stdlib `start` (`@throws`, three variants) always writes `? tick(state)`; at the `tick` redirect in the call check the wrap is dropped (`op.insideTry = false`) when the resolved tick is not `@throws`, so the two-way rule holds. A throw from `main` or `tick` is reported by `eventLoopReport` (`stdlib/event_loop_fail.caspien`, stderr via `write`) and the program exits 1. Tests `event_loop_{tick,main,tick_always}_throw_test` + `event_loop_throw_check.sh`.
**Throw/try.** `@throws` is mandatory on any function containing `throw` AND such a function must contain a real `throw`. Every call to an `@throws` function, `new`, `clone`, safe `dyn`/`resize`, `par`, `await` must be wrapped: `try EXPR catch(e){..}` or `?EXPR`. `catch(e)` takes exactly one untyped name (type `static imut string`); the catch body must end every path in `return`, `throw` or `continue`. `?catch(e){..}` declares the pending catch (unscoped, reset per function; `?EXPR` expands in the Parser before RPN). `try{ ... }` block: lexical scope, zero code, must contain a real try/catch; `continue` (catch-only) jumps past the nearest enclosing `try{}` block. `return ?f(x)` is supported. `throw` is banned anywhere reachable from `@gt_*` functions.
**Overloading/constructors.** Plain functions, bare-impl methods (instance and static) and constructors overload by parameter base types (mutability/storage do not distinguish); first overload keeps the plain mangled name, others get `__sig_<suffix>`. `impl constructor for X(..) self{}` (generic: `impl<T> constructor for X<T>`, one wrapper impl each, decorators on the constructor); `X(..)`, `new X(..)`; struct-literal `X{..}` only inside X's own constructors (OTC lockout). Generic impl methods are checked lazily: a method whose signature is illegal only for the chosen T (by-value struct parameter) is dropped and reported when called.
**RVO.** A struct-returning function gets hidden first param `$ret_dest raw mut S`; a call is legal only as a `let` RHS, bare-variable assignment RHS, or `return f()` (tail forward); methods and `?` included. `return` operand: struct literal, readable value chain, or such a call.
**Recursion.** Only a `@recursive` function with a final `imut range` parameter whose self-call is the sole expression of a `return` inside `match r2 within r`; lowered to a bounded `for` plus a copied base case after the loop (`lowerRecursiveFunctionToLoop`). All other recursion is an error.
**Async.** `@async` function: at most one parameter, <=8 bytes scalar/pointer (no range, no struct). `par f(x)` / `await f(x)` must be wrapped in `try`/`?` (checkTry accepts them; `usesThrow` is set) and desugar in `emitAsyncCall` to handle `NEW`+`GT_REGISTER`+null check ("out of memory"), a synthesised `__trampoline_<f>` (pthread entry), a call to the `@par_call`/`@await_call` stdlib function (returns `bool`; false -> destruct the handle and moved-in args, "cannot start thread"), then `.result` read + `GT_DESTRUCT` (await) or handle value (par non-void). Void `par` uses a self-destructing trampoline. A value-returning `par` handle (`getOrCreateAsyncHandleType(..., locked)`, key suffix `|par`) is a swap-lock struct built in memory: `gate` first (`AsyncGate` OPEN/CLOSED, `lockFieldName`/`swapFieldName` set programmatically), then `state`, `value`, `threadId`, `result`; its `resolve()` carries `@lock(match self.gate : OPEN)`; `par` uses trampoline `__trampoline_<f>__par_locked` (writes result+state inside `match @lock`, unbounded retry) and a synthesised `@drop` hook `__join_<Handle>` (`synthesizeAsyncDropHook`, joins `threadId` when nonzero); `await` keeps the plain handle and trampoline. Compiler-written glue is checked with `synthesizingGlueBody` (no lock proofs, no retry bound). `@par_call` takes a third parameter `tidOut: raw mut u64` (the handle's `threadId`, or null = detach). Must-match rule: a local owns `par` handle needs a `match @lock` on it somewhere or must be moved/returned (`fnHandleDecls/fnLockMatched/fnEverMoved`). `yield` -> `YIELD`; `sleep(n)` -> `SLEEP <fn> u64` resolving the `@sleep` function; `join` does not exist.
**Ghost table.** Decorators `@gt_init`, `@gt_alive_check`, `@gt_destruct`, `@gt_register` (returns `bool`: false = could not grow the table; the emitter puts `GT_REGISTER` before the allocation's null check), `@gt_moved`, `@gt_ref_id` (`func(ptr: raw u8) u64`, 0 for null/dead) and `@gt_ref_resolve` (`func(id: u64) raw u8`, null for dead) (one each, fixed signatures; their functions are forced to the literal names `gt_init` etc.); also `@par_call`, `@await_call`, `@sleep`. **Nullable `ref` = id (8 Oct):** a plain `ref` slot holds an id, `ref some`/`owns`/`raw`/`auto`/proven bindings are addresses; TypeChecker only MARKS tokens and BytecodeEmitter acts in `emitExpr` (`Token.refToId`: address stored into a nullable ref -> `GT_REF_ID`, set by `markRefConversion` from `acceptsAdaptingLiteral`/`retagLiteralArgs` (the finally chosen overload only) and by `ref x` of a nullable owner; `refToRaw`: nullable ref handed to a `raw` slot -> `GT_REF_RESOLVE`; `refProofKey`+`refProofIsId` (set in `isProvenAlive` and by `requiresAliveProof`/`argSatisfiesParam`/`checkReturn` when the subject is a nullable ref): the use reads the proof's hidden address slot; `someOnRef`+`someProofKey`: `match Some(r)` emits `emitSomeOnRef` = resolve into the slot (`refAddrSlots`, one hidden `$mvN` per proof key and function), test non-null; an `assume match` proof never ran, so the use resolves the id inline). `==`/`!=` between a nullable ref and an address converts the address side (`normalizeRefComparison`; `null` needs nothing). Stdlib: the default `stdlib/ghost_table.caspien` implements ids; `gt_alive_check.caspien` imports `gt_ref_id.caspien` and `gt_ref_resolve.caspien`. `new` emits `NEW` then `GT_REGISTER`. `new`/`dyn`/`resize`/`clone` hold the pending catch label back while their operands are emitted (a nested call would otherwise consume it and the allocation check would have no catch). Hidden locals (`declareHiddenLocal`, e.g. `$mvN` for a call result moved into `new`/`dyn([..])`) are declared while emitting; their `ALLOC` lines are spliced in after the hoisted allocs when the function ends (no pre-pass). Inside `new`, the null-out of moved-in owns sources is deferred until the allocation succeeds (`deferredMoveNullOuts`); the OOM branch `GT_DESTRUCT`s them instead (same for the owns-variable elements of a `dyn([..])` literal). `usesOwnsRefDynNew` (set by owns/ref/new/dyn/par/await) gates `GT_INIT` in `main` and the unwind machinery.
**Other decorators.** `@drop` (struct cleanup hook, see root CLAUDE.md), `@fs_root`/`@fs_root(rw)`/`@fs_unsafe` (static methods of `Dir`; call-site checks in `checkFsPolicyAtCall`, policy in `FsPolicy`), `@pub`, `@throws`, `@async`, `@inline` / `@dont(inline)` (acted on by the Optimizer's FunctionInliningPass; emitted as `FUNC_DECORATE @x "file:line"`), loop `@unroll`/`@unroll(N)` (N 2..64, a whole number is a legal decorator argument) and `@dont(unroll)` (emitted as `FOR_DECORATE @x "file:line"`; the Optimizer's LoopUnrollingPass acts on them), `@lock`, `@recursive`, `@call_convention(name)`, `@link_name(realName)` (extern only, bare word), `@untyped`, `@default`, `@overrides`, `@realizes`, `@dont(par)`, `@guard`. Unknown ones are rejected (`FUNC_BASE_DECORATORS`/`STRUCT_DECORATORS`). Builtins include `bits_and/or/xor/not/left/right` (shift count >= width gives 0 / sign fill).
**dyn.** `clone(p)`: source must be `auto`/`some`/inside `match Some` in safe code (no run-time null check), throws on alloc failure (needs try/`?`), result `owns some` registered via `GT_REGISTER`; deep copy of owns members is `LowerOrderGenerator/CloneGenerationPass` (call sites `CALL __clone_<T>` use the drop-glue stack-arg call shape in Codegen). `dyn([..])`, `dyn(text)`, `dyn:<T>([])` (only empty literal takes `:<T>`), `resize(d, n, fill)`; safe forms return `owns some`, need try, and their block is `GT_REGISTER`ed (resize re-registers in codegen; its source variable is nulled only after the realloc succeeded, a failure `GT_DESTRUCT`s it); unsafe forms emit `NEW_UDYN`/`URESIZE`.

**File policy/platform.** `fs.config` (optional) and `platform.config` (`target: linux|windows_gnu`) are read from the working directory by `Main`; the lexer turns `__FS_ROOTS` into a string literal of the run-time roots table (`path?rw|path?r`, `*` = unrestricted) and `ImportResolver` replaces `{target}` in an import path. Extern deny-list: `collectExtern` (stdlib files exempt). `--fs-report` (extra arg after the output path) prints `TypeChecker.printFsReport` to stderr. `new T(args)` of a `@throws` constructor stages the pending catch label for the constructor call (`emitNew`); test `ctor_throw_test`.

## HOB conventions downstream stages rely on
- Per function: all `ALLOC_STATIC`, then `ALLOC gt_routine_address` (always first ordinary alloc, rbp-8), then `gt_error_message` right behind it when the program uses throw (rbp-16), then every other ALLOC hoisted from the whole body (collectHoistedAllocs), then prologue/body.
- `ARG name type` lines sit right after `RETURNS`, before the ALLOCs; the optimizer's `ArgToAllocLoweringPass` turns them into slots. The emitter does no register/stack or offset decisions.
- Calls: `CC_START conv` / `POP ARGn` / `CALL f` / `CC_END`; extern varargs emit `PROMOTE_F32_TO_F64`, `VARARGS_XMM_COUNT`, `DUP_TOP` as needed; nested calls rely on codegen saving loaded arg registers.
- Unwinding: before every ordinary call stage `ADDR gt_routine_address / PUSH_LABEL <pad|@catch_N> / ASSIGN`; try-guarded calls stage the catch label directly (no pad). Landing pads sit behind a `JMP` before `FUNC_END`. `throw` emits inline `GT_DESTRUCT`s and lock releases then `EXIT` (main) / `EXIT_THREAD` (async) / `GT_UNWIND MSG` (message copied up one frame). Catch bodies are hoisted after the ALLOCs (`tryCatchLabels`, `collectTryBlockLabels`, `continueTargetLabels` precomputed per function). Function bodies without throw use the old `gt_routine` label/GT_UNWIND path.
- Entry points: the user's `main` of a safe-args program, or of a program with an `@event_loop` function, is emitted as `__caspien_main` (the C-ABI `main` wrapper / the event loop is `main`). Never `__main`: the mingw CRT calls that symbol itself.
- Structs: declaration is `STRUCT_START`, `STRUCT_MEMBER ___type` FIRST (hidden class id, u64 at offset 0, `Class` enum value; flat for all non-`@untyped` structs), user members, `STRUCT_PADDING n` gaps, `STRUCT_END`. Construction pushes class id first, then members, with `STACK_LOCK n` for gaps. `sizeof(Struct)` and `raw Struct` pointer scale are symbolic (`SIZEOF Name`, resolved by the Optimizer); primitives fold at once. `let static n = sizeof(S)` folds here and emits `STRUCT_PIN S`.
- `owns` assignment through a pointer-reached target (`h.w = f(h.w)`, `a[i] = ...`, `isPointerCrossingOwnsTarget`): the right side is spilled to a hidden `$mvN` local first, then the old value is destructed via `DUP_TOP`/`GT_DESTRUCT_ADDR`, then the spilled value is stored. A throwing right side leaves the old value intact. Flat-name targets destruct after the right side (`lateDestruct`). Test: `tests/owns_assign_ptr_test.caspien` + `owns_assign_ptr_check.sh`.

## Known open gaps
- windows_gnu is verified under Wine; there is no MASM target.

## Deliberate limits (not gaps)
- The struct `.enum` form is an error (`x instanceof S.enum`; only an interface has `.enum`, used as `match x implements I.enum{..}`).
- `instanceof`/`implements` tests that are always true are NOT reported, on purpose: the check can still guard against a type damaged through a raw pointer in unsafe code, and a warning would nudge users to delete it. (Never-true tests do warn.)
- `auto` cannot point at a dynarray element: `resize` may move the block and leave the `auto` dangling.
- Structs are never passed by value as parameters (returns use RVO): a struct can grow past 8 bytes when its definition changes, which would silently change how it is passed, so anything over a register must be argument-split, and splitting is only defined for ranges. Pass an explicit pointer instead (`auto`/`ref`), because explicit beats an implicit auto pointer.
- `deref(p) = v` struct-wide assignment is rejected (`deref` is never a write target); an unsafe `resize` has no failure handling (the programmer's job, like C).
- Moving one owns slot twice in one expression (`f(a, a)`, `dyn([a, a])`, `[a, a]`) is rejected by `requireNotMovedAlready` (operands are all checked before any is marked moved).
